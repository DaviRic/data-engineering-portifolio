## Crypto Market Analysis Pipeline

Esse projeto visa monitorara a volatilidade de ativos em tempo real para identificar oportunidades, considerando a mudança frequente dos dados e a necessidade da limpeza desses dados.

O projeto demonstra a construção de um pipeline de dados ponta a ponta para analisar o market share das principais criptomoedas do mercado, consumindo dados reais da API **CoinGecko**
